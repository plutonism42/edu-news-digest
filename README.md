# 교육·과학·정책 데일리 다이제스트

매일 오전 10시(KST) 기준, 전날 10시~오늘 10시 사이에 올라온 교육부·KEDI·KERIS·정책브리핑 등
19개 기관의 공지/보도자료를 모아 요약된 웹페이지를 자동 생성합니다.

## 구조

- `config.py` — 수집 소스 목록(RSS/게시판), 관련 기관 링크 모음
- `main.py` — 전체 파이프라인 실행 (수집 -> 요약 -> 저장 -> 페이지 생성)
- `archive_store.py` — 날짜별 데이터 저장/조회, 누적 CSV 생성
- `generate_html.py` — 정적 HTML 페이지 생성
- `collectors/` — RSS, 게시판 크롤링, 네이버 뉴스 검색 수집기
- `summarize.py` — Claude API로 요약
- `.github/workflows/daily.yml` — 매일 자동 실행 + 수동 실행 버튼

## 페이지 접속 (다이제스트 사이트)

`https://plutonism42.github.io/edu-news-digest/`

- 메인 화면에서 큰 버튼 3개(교육분야/국가정책/과학교육) 클릭해서 카테고리별 전체 목록 확인
- "🔗 관련 기관 홈페이지" 코너 — 자동 수집이 안 되는 곳도 직접 확인 가능
- "🔄 지금 새로고침" 버튼 — GitHub Actions 실행 화면으로 연결 (로그인 후 Run workflow 한 번 더 눌러야 실행됨)
- "📂 지난 기록 전체 보기" — 날짜별 아카이브

## 특징

- **고정 24시간 구간**: 매일 오전 10시를 기준으로 "전날 10시~오늘 10시"를 계산. 언제 새로고침을 누르든 같은 날 안에서는 항상 같은 결과.
- **같은 날 여러 번 실행 시 병합**: 사이트 접속 성공/실패가 매번 랜덤이라, 재시도하면 기존 데이터에 새로 잡힌 것만 추가됨(덮어쓰지 않음).
- **0건이면 보존**: 전체 수집 실패(네트워크 차단 등)로 0건이 나오면 기존 데이터를 절대 덮어쓰지 않고 실패로 종료.
- **중복 기사 우선순위 처리**: 여러 카테고리에서 동시에 잡히는 기사는 과학>교육>정책 순으로 하나에만 배정, 나머지는 배지로 표시.
- **접속 실패 사이트 표시**: 자동 수집이 안 된 사이트는 노란 박스로 표시되어 직접 클릭해서 확인 가능.

## 알려진 한계

- 한국 정부/공공기관 사이트 중 일부는 해외 IP(GitHub Actions 서버)를 차단해서 그날그날 랜덤하게 접속이 실패할 수 있음.
- KOSAC(한국과학창의재단), NIA 등은 자바스크립트로 게시판 목록을 그리는 방식이라 자동 수집이 원천적으로 불가능 — 링크 모음으로만 제공.
- 정책브리핑(korea.kr) 키워드 검색은 실제로 필터링이 안 되는 것으로 확인되어 비활성화됨.
